# PayCreate website preview

[Open the interactive website](https://cduque001.github.io/paycreate-preview/en/?v=release-19)

[Watch the walkthrough and view screenshots](https://cduque001.github.io/paycreate-preview/review/?v=release-19)

Design preview for review with Jason. This release adds the audit fixes: a direct Online section, native no-JavaScript navigation, localized accessible labels and hours, larger founder captions, and branded sharing previews. The static partner action opens the existing localized signup form. The full release candidate is also available at https://website-release-website-staging.up.railway.app/en. The opening payment sequence now runs in a quicker, smoother 3.6-second loop on desktop and phone. The oversized PayCreate footer wordmark is restored. The scene label, illustrative caption, location label, and scroll prompt are removed. Larger useful text, concise fee-review steps, one full pricing comparison on Payment Solutions, and concise Contact and FoodHub sections remain available. Customer logos, Typeform signup, offer conditions, and booking destinations are preserved.

The green-and-white identity, real business photography, and 3.6-second payment sequence remain. Desktop uses interactive 3D; phones play localized lightweight films. The orbit stays behind the products. The preview includes eight public pages in English, Spanish, and French, with responsive layouts, touch controls, and reduced-motion fallbacks.

This repository contains the compiled static marketing preview. The application source, authenticated portal, APIs, private data, and environment configuration are not included. This preview does not replace the production website or the planned Railway deployment. Search indexing is disabled.
