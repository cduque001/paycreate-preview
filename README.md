# PayCreate website preview

[Open the interactive website](https://cduque001.github.io/paycreate-preview/)

[Watch the walkthrough and view screenshots](https://cduque001.github.io/paycreate-preview/review/)

Design preview for review with Jason. Includes the eight public marketing pages in English, Spanish, and French, original 3D product animation, and real business photography. The latest refinement gives phones a dedicated layout with readable text, large touch targets, a full-width call button, balanced product artwork, and booking near the top of the contact page. Tablet and desktop layouts preserve the same green-and-white identity. The 24 pages were checked at eight widths in Chromium and WebKit, including touch controls and accessibility.

This repository contains the compiled static marketing preview. The application source, authenticated portal, APIs, private data, and environment configuration are not included. This preview does not replace the production website or the planned Railway deployment. Search indexing is disabled.
